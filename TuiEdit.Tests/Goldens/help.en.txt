┌─ Help ────────────────────────────────────────────────────────────────────esc┐
│── File ───────────────────────────────────────────────────────────────────── │
│   ^S save (asks for name if new)   Ctrl+Shift+S save as   ^Q quit            │
│── Find & replace ─────────────────────────────────────────────────────────── │
│   ^F find       F3 next / Shift+F3 prev   ^H replace   ^G go to line   Alt+C/│
│── Edit ───────────────────────────────────────────────────────────────────── │
│   ^K cut line  ^U/^V paste  ^C copy line  ^D duplicate  Ctrl+/ comment       │
│   ^C also puts the copy into the system clipboard (Windows Terminal) — paste │
│   ^Z undo  ^Y redo  ^A select all   Shift+arrows — selection                 │
│   Terminal clipboard paste — as full text in a single undo step              │
│── Navigation ─────────────────────────────────────────────────────────────── │
│   arrows/Home/End/PgUp/PgDn, Ctrl+arrows — by word, Alt+up/down — move line, │
│   Enter — new line, Tab — indent, Shift+Tab — unindent                       │
│── Menu ───────────────────────────────────────────────────────────────────── │
│   F10 or Alt+F/E/H — menu (arrows/Enter/Esc, letter hotkey)                  │
│── View ───────────────────────────────────────────────────────────────────── │
│   F1 — this help (arrows — scroll)   Alt+N — line numbers   Alt+Z — word wrap│
│   Ctrl+B — file tree (arrows — walk • Enter — expand/open • F7 — new • F2 — r│
│   Tabs: Ctrl+PgDn/PgUp — next/prev • Ctrl+T — new • Ctrl+W — close           │
│   Alt+1..9,0 — jump • Ctrl+P — tab list • Alt+O — quick open                 │
│   Split: Alt+S — split • F6 — neighbour pane • Ctrl+1..9 — pane N            │
│── File manager ───────────────────────────────────────────────────────────── │
│                          ↑/↓ — scroll • Esc — close                          │
└──────────────────────────────────────────────────────────────────────────────┘
