┌─ Help ────────────────────────────────────────────────────────────────────esc┐
│── File ───────────────────────────────────────────────────────────────────── │
│   ^S save (asks for name if new)   Ctrl+Shift+S save as   ^Q quit   ^N new   │
│── Find & replace ─────────────────────────────────────────────────────────── │
│   ^F find       F3 next / Shift+F3 prev   ^H replace   ^G go to line   Ctrl+S│
│── Edit ───────────────────────────────────────────────────────────────────── │
│   ^K cut line  ^U/^V paste  ^C copy line  ^D duplicate  Ctrl+/ comment  ^L su│
│   ^C also puts the copy into the system clipboard (Windows Terminal) — paste │
│   ^Z undo  ^Y redo  ^A select all   Shift+arrows — selection                 │
│   Terminal clipboard paste — as full text in a single undo step              │
│   Multicursor: Alt+Shift+Up/Down add, Alt+D next occurrence, Esc clears      │
│── Navigation ─────────────────────────────────────────────────────────────── │
│   arrows/Home/End/PgUp/PgDn, Ctrl+arrows — by word, Ctrl+BS/Del — delete word│
│   Enter — new line, Tab — indent, Shift+Tab — unindent                       │
│   Go to definition (textual): Alt+G, back with Alt+Left                      │
│   Review changes: Alt+R, pick a hunk to jump to it                           │
│── Menu ───────────────────────────────────────────────────────────────────── │
│   F10 or Alt+F/E/H — menu (arrows/Enter/Esc, letter hotkey)                  │
│── View ───────────────────────────────────────────────────────────────────── │
│   F1 — this help (arrows — scroll)   Alt+N — line numbers   Alt+Z — word wrap│
│   Ctrl+B — file tree (arrows — walk • Enter — expand/open • F7 — new • F2 — r│
│   Tabs: Ctrl+PgDn/PgUp/Ctrl+Tab — next/prev • Ctrl+T — new • Ctrl+W — close  │
│                          ↑/↓ — scroll • Esc — close                          │
└──────────────────────────────────────────────────────────────────────────────┘
